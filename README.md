# Toolbox

The [Toolbox](https://mitchilaser.github.io/web-toolbox/) is a collection of useful tools for lab courses, combined into a single website.

## Introduction

The Toolbox is a set of useful tools, making a lab course easier. All calculations are being performed on the client side. Just Copy-Pasta the files onto your web-server and you're ready to run.

Currently the only supported language is German 🇩🇪, which might get extended in the future.
